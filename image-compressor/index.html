How to compress an image

  1. Add one or more images by dropping them in the box or choosing them.
  2. Set a quality, or type a maximum file size in KB if a form or website has a limit.
  3. Check the new size, then press Download for each file.

What makes an image smaller

Four things change a file size, roughly in this order of effect:

  • Dimensions: halving the width and height cuts the pixels to a quarter. Use the image resizer or the maximum width option.
  • Format: JPEG and WebP are far smaller than PNG for photos.
  • Quality: a lower quality discards more detail. The gains get smaller and the damage larger at the low end.
  • Metadata: re-encoding drops camera data such as EXIF, including location.

The guide to reducing image size goes through each one.

Frequently asked questions

How do I compress an image without losing quality?

Some quality is always lost with JPEG and WebP, but a moderate setting, around 75% to 85%, usually looks the same to the eye while cutting the file a lot. Resizing very large pictures first saves even more.

Is my image uploaded to a server?

No. The image is decoded and re-encoded in your browser, so it never leaves your device.

Can I compress to an exact size, like 100 KB?

Yes. Type a maximum file size in KB. The tool finds the highest quality that fits, and reduces the dimensions if quality alone cannot get there. There are also ready-made pages for 20 KB, 50 KB and 100 KB.

Should I choose JPEG or WebP?

JPEG works everywhere. WebP gives a smaller file at similar quality, but some older programs and forms do not accept it.

Why did my PNG get a white background?

JPEG and the lossy mode of WebP here do not keep transparency, so see-through areas are filled with white. Keep the PNG if you need transparency.

Is there a limit on file size or number of files?

No limit is set here. Very large photos use a lot of memory in the browser, so a huge file may be slow or fail on a phone.
