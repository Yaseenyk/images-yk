Photo upload rejected? How to hit a 20 KB, 50 KB or 100 KB limit

Application portals, job sites and government forms often accept only small images. The rejection message is usually short, so it helps to know the handful of things a form can be checking and how to fix each one.

What the form may be checking

  • File size: a maximum, and sometimes a minimum too, in KB or MB.
  • Pixel dimensions: an exact width and height, or a range.
  • Format: JPG or PNG. A file renamed from PNG to .jpg is still a PNG inside and may be rejected.
  • Content: for photos, framing, background and face size.

Read the instructions for all of them before you start; fixing only the size and being rejected for the format is the common trap.

Step by step

  1. Crop first. Cut the picture to the area that matters. Fewer pixels means a smaller file at the same quality.
  2. Resize to the required pixels, if the form states them, with the image resizer.
  3. Compress to the limit. Open the page for your limit: 20 KB, 50 KB or 100 KB. The tool finds the best quality that fits.
  4. Check the result: size, pixel dimensions and that it looks clear when zoomed in.

If it will not get small enough

A very detailed picture at large dimensions cannot reach a tiny limit at good quality. Reduce the pixel dimensions, or use a plainer background; a face on a plain background compresses far better than a busy scene. Signatures on white paper compress very well.

If it is too small

Some forms set a minimum as well as a maximum. If the compressed file is under the minimum, compress to a higher limit, for example 100 KB instead of 50 KB, and check the result lands in the allowed range.

Keep your photos private

ID-style photos are sensitive. Many online compressors upload the file to a server. The tools here work in your browser, so the picture never leaves your device, and the saved file has its camera and location data removed.

KB, kilobytes and what the form means

A kilobyte is 1,000 bytes in the decimal convention and 1,024 bytes in the older binary one, and portals do not say which they use. The size tools on this site aim at the smaller figure: a 50 KB target means at most 50 x 1,000 = 50,000 bytes, which is also under 50 x 1,024 = 51,200 bytes, so the file passes under either reading. File managers differ too, so a file shown as "48.8 KB" in one program can be "50,000 bytes" in another; the byte count is what the portal compares.

Worked example: a passport-style photo for a 50 KB limit

A photo from a phone is, say, 3024 x 4032 pixels and 2.6 MB. The form asks for a JPG under 50 KB and gives no pixel size. Cropping to the head and shoulders and resizing to about 600 x 800 leaves 480,000 pixels, about 4% of the original 12.2 million, which is more than enough for a small on-screen portrait. At that size a photo on a plain background will often land under the limit near the middle of the quality range; a cluttered background needs a lower setting and may not. Look at the result at 100% zoom before you upload: if the face is clear, the file is good; if edges are blocky, go back to the original and crop tighter instead of lowering quality further.

Common reasons a form still rejects the file

  • The pixel dimensions are outside the range the form states, even though the size is fine.
  • The file is a different format inside than its extension says (a renamed PNG).
  • The file is below a stated minimum size because it was compressed too far.
  • The form measures the size in its own way, for example counting a different unit; read the instructions again for the exact wording.
  • The photo rules were not met: background colour, face position or no glasses. No tool can fix those afterwards; retake the picture.

These numbers and rules are general. Each portal sets its own, so follow the instructions on the form you are using; this guide cannot know them.
