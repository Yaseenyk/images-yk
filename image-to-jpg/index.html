How to convert Image to JPG

  1. Add images of any kind, in one batch if you like. Each is converted on your device and never uploaded.
  2. Pick the background colour for transparent areas, and the quality. The defaults are white and 92%.
  3. Check each result line. A file the browser cannot read shows a message and the rest carry on.
  4. Press Download on each. Every file is named like original-converted.jpg.

What happens to each kind of image

This converter does not read formats itself. Your browser decodes each file, so the list depends on the browser. The file chooser accepts any file marked as an image, and files ending in .avif, .webp, .jpg, .jpeg or .png.

Why convert to JPG

JPG is a lossy format that every major browser and nearly all software and upload forms accept. Screenshots, web downloads and phone photos often arrive as PNG, WebP or AVIF, which some forms reject.

Choosing the quality

  • 92% is the starting point: a good balance for photos you may print or reuse.
  • Around 75% to 85% makes a clearly smaller file for web pages and email.
  • Below about 50%, blocky artefacts are easy to see.
  • For a file under a set size, use the compress pages, which choose the quality for you.

Transparency, animation and metadata

JPG has no transparency, so the tool paints your background colour first and draws the picture over it. Semi-transparent edges blend with that colour. JPG also has no animation, so only a still is saved: a canvas draws an animated image as its default image or first frame.

The tool saves only pixels. It never reads or writes metadata, so camera details, GPS position and text notes stored in the original are not copied to the new file. If the original had an EXIF rotation tag, the browser applies it when it reads the picture, so the result is the right way up.

What this converter leaves out

  • No resizing: the picture keeps its pixel size. Use the image resizer.
  • No HEIC support in most browsers.
  • Pictures over 120 million pixels are refused.
  • No upload and no account, so nothing is stored for you to come back to.

Privacy

The conversion code does not call fetch, XMLHttpRequest or a beacon. The browser decodes the file, the tool draws it on a canvas and saves the canvas, and the download button points at a temporary link held in your own browser's memory. The page loads its own scripts, such as analytics, but none of them is given your picture.

Frequently asked questions

How do I convert an image to JPG?

Add the images, choose the quality, and download the JPGs. The conversion runs in your browser, so nothing is uploaded.

Which formats can I convert to JPG?

Any format your browser can display, including PNG, WebP, GIF and JPG. AVIF works in browsers that support it, such as current Chrome, Edge, Firefox and Safari.

Can I convert HEIC photos from an iPhone?

Probably not. This tool can only read what your browser can decode, and most browsers cannot read HEIC. Setting the camera to save JPG avoids the problem.

What quality should I choose?

About 90% is a good default: files are much smaller than PNG and the difference is hard to see. Lower it for a smaller file, or raise it for photos you will print.

What happens to transparent backgrounds?

JPG cannot be transparent, so transparent pixels are painted with the background colour you pick, white by default.

What happens to an animated GIF or WebP?

Only a single still is saved, because JPG cannot be animated.

Can I convert many files at once?

Yes. Select several files and each is converted and listed with its own download button. A file that cannot be read shows an error without stopping the others.

Does the JPG keep camera and location data?

No. Only pixels are saved, so EXIF and GPS data are not in the result.

Does it make the picture smaller in pixels?

No. The pixel size stays the same. Use the image resizer to change it.
