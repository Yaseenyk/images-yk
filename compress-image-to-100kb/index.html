How to compress an image to 100 KB

  1. Add your image. It stays on your device.
  2. The maximum file size is already set to 100 KB. The tool finds the best quality that fits.
  3. Press Download. If it says the limit could not be reached, set a smaller maximum width and try again.

About a 100 KB limit

100 KB is a roomy limit for a web photo. A modest-sized picture usually keeps good quality at this size, while a full camera photo still has to be reduced a long way.

Because the tool searches for the highest quality that fits, you get the best-looking file under 100 KB rather than a fixed preset quality that may be far below the limit.

Tips for staying under 100 KB

  • For web pages, a maximum width of about 1200 px is plenty for most layouts.
  • Screenshots and graphics with flat colours often compress better as WebP.
  • If you need an exact pixel size too, resize first, then compress.
  • Compare the result to the original before you delete anything.

Frequently asked questions

How do I compress an image to under 100 KB?

Add the image, keep the maximum file size at 100 KB, and download the result. The tool picks the highest quality that fits and shrinks the dimensions only if needed.

Will quality drop a lot at 100 KB?

For a web-sized picture, usually not noticeably. A very large, detailed photo will lose more because it has to be reduced further.

Is it safe for private photos?

Yes. The processing happens on your device and nothing is uploaded.

What if the tool says it could not reach 100 KB?

The picture is very large or very detailed. Set a smaller maximum width and try again; the message shows the smallest result it managed.

Does it remove the photo's location data?

Re-encoding on a canvas drops metadata such as EXIF, including GPS location, from the output file.
