How to compress a JPEG

  1. Add one or more JPEG files, or drop them in the box.
  2. Pick a quality, or type a maximum file size in KB if a form or website has a limit.
  3. Compare the sizes shown and press Download for each result.

Choosing a quality

QualityTypical use
90% and upPhotos you will print or edit again
75% to 85%Web pages, email and sharing: the best balance
50% to 70%Thumbnails and strict size limits
Below 50%Only when nothing else fits; artefacts are visible

Dimensions matter even more than quality: halving the width and height cuts the pixels to a quarter. See the guide to reducing image size, or use the image resizer first.

Frequently asked questions

How does JPEG compression work?

JPEG discards detail the eye is least likely to notice, mostly fine colour and texture, and stores what is left efficiently. A lower quality setting discards more, so the file is smaller and the picture is less exact.

What quality should I use for a JPEG?

Around 75% to 85% is a sensible starting point for photos: much smaller than the original with little visible change. Below about 50%, blocky artefacts around edges become easy to see.

Can I compress a JPEG to an exact size like 100 KB?

Yes. Type a maximum file size in KB. The tool finds the highest quality that fits and reduces the dimensions in steps if quality alone is not enough.

Does compressing a JPEG again make it worse?

Yes. Every lossy save discards a little more detail, so compress from the original file when you can and avoid re-saving the same JPEG many times.

Is my photo uploaded?

No. The JPEG is decoded and re-encoded in your browser. It never leaves your device, and the saved file has its camera and location data removed.
