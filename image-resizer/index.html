How to resize an image

  1. Add your image.
  2. Enter a width or a height in pixels, or a percentage to scale by.
  3. Keep Keep aspect ratio ticked so the picture is not stretched, then download the result.

The calculation

new height = original height x (new width / original width)

An image 4000 x 3000 pixels resized to a width of 800 becomes 800 x 600. The tool does this for you and rounds to whole pixels.

Resizing for a file-size limit

If a form wants both a pixel size and a small file, resize first, then run the result through the image compressor with a maximum size. See how to get a photo under a form's size limit.

Frequently asked questions

How do I resize an image to a specific size in pixels?

Enter the width, the height, or both, and download the result. With Keep aspect ratio ticked, entering one side works out the other so the picture is not stretched.

What happens if I enter both a width and a height?

With Keep aspect ratio on, the image is fitted inside that box without distortion, so one side may come out smaller than you typed. Untick it to force the exact size, which can stretch the picture.

Can I resize by percentage?

Yes. Enter a percentage in Or scale by. 50 makes the image half as wide and half as tall, which is a quarter of the pixels.

Will making an image bigger improve it?

No. Enlarging only stretches existing pixels, so it looks softer. Resize down whenever you can, and start from the highest-resolution original.

Does resizing change the file size?

Yes, usually a lot. Fewer pixels means a smaller file. To hit an exact file size as well, resize first and then use the image compressor.

Is my image uploaded?

No. Resizing happens in your browser and the file never leaves your device.
